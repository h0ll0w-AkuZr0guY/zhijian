# 使用说明

[返回项目首页](../README.md)

## 从一份文档开始

在线版首次打开会展示虚构示例。可直接编辑，也可通过「文件」新建空白文档、打开工程或进入本机文档库。「导入文档」支持 PDF、Markdown 和图片。

建议先完成内容校对和模板整理，再进入自由画布细调，最后导出。重要修改可以下载 `.zhijian` 工程留作备份。

## 内容填写

顶部点击「内容填写」，进入左侧表单、右侧预览的界面。右侧用于查看效果，字段与内容通过左侧表单修改。

- 基本信息包含姓名或标题、副标题、联系方式、作品集、照片及个人简介。
- 教育、工作或实习、项目、研究等模块提供相应字段，描述区支持加粗、斜体和列表。
- 点击条目展开填写，通过底部按钮添加经历，使用箭头调整条目或模块顺序，模块标题可以修改。
- 用「添加模块」补充技能、成果或自定义内容。
- 描述下的「填写提纲」可帮助组织背景、行动与结果。已有内容时会显示写作提示。
- 「检查填写」检查已填字段的格式与占位内容。AI 建议入口位于描述下方。

已有简历会尝试预填字段，请核对识别出的组织、岗位和时间。首次切换保留现有画布，修改表单或选择模板后触发自动排版。多页连续排列，向下滚动查看。

## 自由画布

点击「自由画布」后，可在任一页直接选择和编辑元素。左侧添加文字、图片、线条、图形和背景，右侧调整所选元素的尺寸、位置、样式与顺序。部分细项折叠在属性分组中。

双击文字进入编辑，点击空白处退出。拖动空白处框选，Shift 追加选择，Alt 拖框减选。多选后可批量改字号、颜色等属性，也可组合、整体缩放、对齐与等距分布。右键菜单提供复制、排列、组合和局部美化等常用操作。

表单生成的文字在自由画布修改后，会映射回相应字段。额外文字归入补充模块。返回表单并再次修改后，模板会重新安排文字位置，支持 Ctrl+Z 撤销。自由画布额外添加的图形与图片保留在工程中。

## 对齐吸附与同行绑定

1. 在自由画布右键学校等锚点文字，选择「创建横向绑定基线」。
2. 将专业或日期拖近虚线，自动吸附绑定，也可右键选择「绑定到基线」。
3. 移动学校时，已绑定的同行字段一起移动。
4. 拖离基线或右键「解除行绑定」可解除关系。

「视图」菜单可控制对齐吸附、网格与基线显示。虚拟基线用于编辑，导出时隐藏。绑定关系随工程保存，复制页面时会更新对应引用。

## 导入与校对

| 来源            | 处理方式                         | 校对重点                     |
| --------------- | -------------------------------- | ---------------------------- |
| Markdown        | 提取标题、段落、列表、强调和表格 | 标题层级、段落顺序           |
| 文字型 PDF      | 提取文字位置与图片，合并碎片     | 同行字段、多栏顺序、字体替代 |
| 扫描 PDF / 图片 | 中英文 OCR，可强制识别           | 姓名、日期、标点、技术缩写   |

导入窗口左侧校对内容块，右侧选择版式与预览。可以调整块类型、顺序，合并或拆分内容，之后点击「应用到画布」。

展开「原稿对照」可查看对应页，并拖框截取照片或图标。选择保留文字位置时按原稿坐标生成元素，选择模板时根据校对后的结构重排。复杂绘图和特殊字体可能需要手动补充。

已有工程可在自由画布的「模板与内容整理」中合并碎片。多选文字后，右键「合并为一个文字框」也可手动整理。

## 模板、美化与智能1页

内容填写模式的「模板」侧栏提供简洁单栏、技术项目、学术科研、双栏信息，以及通知、求职信和项目介绍版式。自由画布也可通过内容整理窗口选择模板。

顶部美化风格包含专业蓝、清爽绿和简约黑，用于统一文字层级、配色、对齐和段落间距。多选后右键可局部美化。

顶部「智能1页」先预览合并比例和最小字号，确认后应用。填写模式的模板侧栏还可开启「固定为1页」，使后续表单编辑持续适配一页。内容较多时字号会缩小，请检查阅读效果，也可关闭固定一页、保留自动分页。

字体选择在空选时作用于整份文档，选中文字时作用于所选文字。微软雅黑、宋体、新罗马等系统字体依赖设备安装情况，浏览器会按本机字体环境回退。PDF 使用思源黑体时导出矢量文字，系统字体以高分辨率外观与可复制文字层输出。

## 保存与导出

| 格式 / 入口            | 用途                                                |
| ---------------------- | --------------------------------------------------- |
| 自动保存与本机文档库   | 在同一浏览器和站点继续编辑                          |
| 文件 → 保存工程        | 下载 `.zhijian`，保留页面、填写数据、图片与编辑信息 |
| 文件 → 打开工程        | 载入 `.zhijian`，兼容旧 `.a4canvas` 工程            |
| 下载 PDF               | 导出全部 A4 页面，可选择文字                        |
| 文件中的 PNG 导出      | 导出当前可见页                                      |
| 文件中的 Markdown 导出 | 导出文字内容与结构                                  |

工程适合继续编辑和跨浏览器迁移。PDF 适合阅读与打印，重新导入 PDF 会重新提取元素。PNG 是图片，Markdown 保存内容结构。网页与桌面版的本机文档库独立，迁移时下载并打开工程。

## 常用快捷键

| 操作                | 快捷键                           |
| ------------------- | -------------------------------- |
| 撤销 / 重做         | Ctrl+Z / Ctrl+Shift+Z，或 Ctrl+Y |
| 保存工程            | Ctrl+S                           |
| 组合 / 取消组合     | Ctrl+G / Ctrl+Shift+G            |
| 追加选择 / 减选     | Shift 点选或框选 / Alt 框选      |
| 缩放画布            | Ctrl+滚轮，或 Ctrl++ / Ctrl+-    |
| 原始大小 / 适合窗口 | Ctrl+0 / Ctrl+1                  |
| 平移画布            | 自由画布中空格拖动或中键拖动     |
| 关闭右键菜单        | Esc 或点击菜单外                 |

文字输入时部分按键由输入框或富文本编辑器处理。自由画布「视图 → 快捷键说明」提供完整列表。

## 常见问题

### 更新后仍看到旧界面

刷新页面，再检查顶部是否出现「内容填写 / 自由画布」。必要时强制刷新。清理站点数据前先下载工程备份。

### 换浏览器后文档不见了

本机文档库按浏览器与站点地址隔离。请在原浏览器下载工程，再在目标浏览器打开。隐私窗口和站点数据清理也会影响保留。

### OCR 首次加载较慢

在线版需要从站点加载识别运行时与语言资源。等待进度完成，或取消后重试。Windows 安装包随附 OCR 资源。识别结果仍应对照原稿校正。

### 学校、专业和时间仍然分开

自由画布保留独立字段便于对齐。需要同行联动可创建绑定基线，需要整体编辑可合并文字框。模板会按识别出的条目结构排版。

### AI 连接失败

在模型设置中核对端点、模型名称和 Key，检查服务是否允许浏览器跨域请求。详细排查见 [AI 与数据说明](AI_AND_DATA.md)。

### 关闭桌面窗口后程序还在

关闭窗口会隐藏到托盘，识别任务可以继续运行。通过托盘菜单「退出纸间」结束进程。
