## 配置自己的模型

顶部「AI 助手」或填写模式的侧栏入口可打开 AI 工作台。进入「模型设置」，选择服务预设或自定义端点，填写模型名称和 API Key，保存后测试连接。

接口使用 Chat Completions 兼容格式。Base URL 会自动补全 `/chat/completions`，也可填写完整端点。模型名称与服务地域以提供商控制台为准。项目提供 DeepSeek、阿里云百炼和自定义配置入口。

远程端点使用 HTTPS，本机端点可使用 `http://localhost` 或 `http://127.0.0.1`。Key 填入独立密钥框。请求从当前浏览器直接发往端点，服务或网关需允许该页面来源的跨域访问。网页的 HTTPS 上下文、本机网络访问权限及服务配置也会影响本地端点连接。

## 选择处理范围

| 入口                          | 操作                                             |
| ----------------------------- | ------------------------------------------------ |
| 条目中的 AI 起草              | 根据当前已填背景生成带待补充占位符的提纲         |
| AI 润色                       | 为当前描述提供改写建议                           |
| AI 加粗                       | 从原文匹配重点短语并标记加粗                     |
| 改写划选 / 划选后右键         | 仅处理所划选的文字                               |
| 工作台中的整份文档 / 当前选择 | 预览发送范围并批量生成建议                       |
| 模拟面试                      | 根据文档和目标岗位开始提问，回答后继续反馈与追问 |

生成后可校对、编辑建议，点击「替换这一段」采用，或勾选后批量应用，支持撤销。加粗建议会校验是否来自原文。原文在生成后发生变化时，需要重新生成建议再应用。

面试记录可以下载为 Markdown。未知资历、成果和数字应由本人补充并核对。项目的 AI 交互回归使用模拟接口，真实模型输出质量取决于配置的服务与模型。

## 数据流向

| 数据                                | 保存或处理位置                                   |
| ----------------------------------- | ------------------------------------------------ |
| 导入文件、PDF 解析、OCR、排版与导出 | 本机浏览器或桌面 WebView                         |
| 文档与填写数据                      | 当前站点的 IndexedDB，下载工程可备份             |
| 部分站点与识别资源                  | 浏览器缓存，在线版首次访问从站点加载             |
| 模型端点、名称与 Key                | 默认 sessionStorage，勾选记住后使用 localStorage |
| 点击生成或测试连接的请求            | 直接发送到所配置的模型端点                       |
| 模拟面试                            | 模型请求包含文档文字、目标岗位与本轮对话上下文   |

当前实现采用静态前端与 Tauri 桌面壳。站点访问会请求页面和资源，主动使用 AI 会向模型服务发送预览范围内的文字。模型服务的数据留存与费用按你选择的提供商处理。

sessionStorage 的保存范围为当前标签页会话，localStorage 在浏览器清理前持续保留。模型设置中可点击「清除密钥」。浏览器存储中的 Key 按应用配置保存，能访问该浏览器资料的其他人也可能访问这些数据。

`.zhijian` 工程打包页面、图片、填写数据及可能存在的导入原稿预览。模型配置与 API Key 单独保存在浏览器设置中。发布反馈或分享工程前，请检查画布、隐藏图片、填写字段与原稿预览中的姓名、电话和其他个人资料。

## 常见连接问题

- **连接失败**。检查端点是否可达，以及服务是否支持浏览器跨域请求。可使用自己配置的兼容网关。
- **401 / 403**。检查 Key、服务权限与配置的地域或端点。
- **模型名称为空或不存在**。填写控制台提供的模型标识。
- **输出截断或格式不完整**。缩小处理范围、调整要求后重试，或更换兼容模型。
- **内容已变化**。重新选择文字并生成建议，避免覆盖刚刚编辑的内容。

反馈连接问题时，可提供状态码、端点类型与脱敏后的报错。API Key、Authorization 请求头和真实简历内容应从截图和日志中移除。
