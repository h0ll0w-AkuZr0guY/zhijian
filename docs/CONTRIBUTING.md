# 贡献指南

[返回项目首页](../README.md)

欢迎改进交互、导入识别、模板、AI 工作流、测试和文档。可先通过 Issue 描述希望完成的操作、遇到的障碍和预期结果。

## 反馈问题

请提供应用版本、在线版或桌面版、浏览器与系统、复现步骤、预期行为和实际结果。导入或排版问题可附最小复现文件，使用虚构资料保留触发问题所需的结构。

截图和工程中请移除真实姓名、电话、邮箱、照片等个人资料。AI 连接反馈还应移除 Key 和请求头中的凭据。工程可能包含原稿预览与额外图片，分享前请一并检查。

## 提交改动

1. Fork 仓库并创建描述改动目的的分支。
2. 按 [开发指南](DEVELOPMENT.md) 安装依赖并启动。
3. 保持改动与目标相关，复用已有模型和逻辑，照顾旧工程兼容性。
4. 运行 `npm run check`、`npm test`、`npm run build`，按修改范围补充验证。
5. 提交 PR，说明用户可见变化、实现要点、验证结果及仍待验证的环境。

界面改动请附截图或简短操作记录。模板与导入调整应检查多页、长段落、中英文混排、图片和导出结果。涉及字体时说明实际测试设备的字体环境。

AI 辅助编写的代码同样需要审阅与验证。描述已执行的测试以及模拟接口使用情况。截图、测试夹具和提交记录使用虚构或脱敏内容。

## 文档与示例

使用实际界面中的按钮名称，区分当前已实现能力与未来想法。新文档加入 README 导航，图片放在 `docs/assets/` 并注明来源。项目截图优先采用内置虚构示例。

第三方资源需要保留来源和许可信息。新增依赖时说明用途，并更新对应第三方声明。
