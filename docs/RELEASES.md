# 发布记录

[返回项目首页](../README.md) · [全部 Releases](https://github.com/h0ll0w-AkuZr0guY/zhijian/releases)

## v1.2.2

- PDF 使用浏览器排好的文字外观，减少标题、正文与分隔线之间的位置差异，保留可搜索文本和矢量线条。
- 导入和新建文字框自动适配高度，新增横向和纵向拖柄，便于单独调宽或调高。
- 多选线条可逐条应用统一线长和线宽，也可切换为等比缩放选区。

## v1.2.1

- 自由画布支持 0.1 mm、0.2 mm 等细线，导出保留矢量线宽。
- 增加纸张中心、三等分与四等分的拖动吸附、临时参考线和精确对齐。
- 新增直角梯形与等腰梯形，支持斜边调整、翻转、快捷旋转和独立圆角。
- 划选文字可局部修改字体、字号、颜色及加粗，工程、页面预览与导出保留样式。

## v1.2.0

2026-11-12 · [版本与安装包](https://github.com/h0ll0w-AkuZr0guY/zhijian/releases/tag/v1.2.0)

- 增加「内容填写 / 自由画布」切换，共用工程、自动保存和撤销记录。
- 模块表单预填已有简历，提供富文本、照片、填写提纲及条目和模块增删排序。
- 多页连续展示，自由画布可直接点击任一页编辑，收起常驻图层与翻页控件。
- AI 起草、润色、加粗、划选改写与单段替换放进模块，模型设置和模拟面试使用侧栏。
- 模板侧栏支持固定为1页，保留额外图形和图片，处理重复适配的缩放累计问题。
- 增加表单映射、字段删除、图片资源往返和额外元素几何信息的回归测试。

首次切换填写模式保留现有排版，修改表单或选择模板后按模板更新页面。AI 仍使用用户配置的兼容接口和 Key。
